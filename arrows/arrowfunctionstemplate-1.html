Arrow Functions

This function is adapted from a portion of my studio 2 project code. This function takes the price of the object currently on display as a parameter, and if it's less than $6.60, it changes the color of the first h1 to light blue.

Named Function

            function priceEvaluation(price){
                if (price <= 6.6) {
                    document.querySelector('h1').style.color = 'lightblue'
                }
            }

Function Expression

            const priceEvaluation = function(price){
                if (price <= 6.6) {
                    document.querySelector('h1').style.color = 'lightblue'
                }
            }

Arrow Function

            const priceEvaluation = price => {
                if (price <= 6.6) {
                    document.querySelector('h1').style.color = 'lightblue'
                }
            }
